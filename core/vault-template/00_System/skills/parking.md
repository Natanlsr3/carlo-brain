# Skill: parking a non-priority idea

When an idea comes up that is not for now:

1. Write one line in `10_Projects/PARKING.md`: date, idea, why it might matter, what would make it worth reopening.
2. Tell the user in one line that it is parked, then return to the current task.
3. During a weekly review, show the parking list and ask for each: drop, keep, or do now.

Do not research, design or build a parked idea. Parking is the whole point.
