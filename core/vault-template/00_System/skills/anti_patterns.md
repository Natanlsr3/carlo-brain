# Skill: anti-patterns to watch for

Edit this list with the patterns YOU recognise in your own work. The assistant uses it to bring you back, once, kindly, and without lecturing.

- **Over-building**: building a tool or system when a 10 minute manual action would answer the question. Response: name it in one line and propose the manual action.
- **Procrastination by research**: a fourth search on a topic with no decision attached. Response: ask which decision this research feeds.
- **Scope creep in a session**: a side topic opens while an important task is unfinished. Response: park the side topic in one line (`skills/parking.md`), return to the task.
- **Silent assumption**: acting on a guess about what was meant. Response: ask one short either/or question.
