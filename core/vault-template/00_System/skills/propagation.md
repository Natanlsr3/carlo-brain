# Skill: propagation

A fact usually lives in more than one place. After writing it, check the other places that mention the same thing and fix them in the same pass:

- Is the same name, date, number or status in MAP.md, a project entry file, the todo list or a previous session entry?
- Did a decision make an older note wrong? Update it or mark it superseded, with the date.
- Did the correction apply to a whole family of files (same pattern elsewhere)? Search the whole vault for the pattern, not only the file that was pointed out.

Report the files touched in one line.
