# SESSION_LOG

Journal of ALL Claude Code sessions. Every session is one entry, no exception.

Window: the last 30 days, newest on top. Older entries move to `90_Archive/SESSION_LOG_YYYY-MM.md` (search with grep).

## Formats

**Full** (long, strategic or multi-topic sessions):
```
### YYYY-MM-DD ~HH:MM (surface) [project] short title
- **Domains**: tag1, tag2
- **Topics**: ...
- **Done**: ...
- **Decisions**: ...
- **Next**: ...
- **State**: ...
```

**Light** (short sessions, one topic):
```
### YYYY-MM-DD ~HH:MM (surface) [project] short title
- **Domains**: tag1
- **Summary**: one line
- **Delivered**: what was produced or changed
```

An entry titled `[auto] (auto, to complete)` was written mechanically by the memory module because the session wrote none. Complete it when you next see it.
