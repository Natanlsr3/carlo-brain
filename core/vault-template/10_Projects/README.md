# Projects

One folder per project: `10_Projects/<name>/`. Each has an entry file `<name>.md` that the assistant reads BEFORE working on the project (list it in `00_System/MAP.md`).

Suggested entry file:

```markdown
# <Project>
**Goal**: one line.
**State**: where it stands today, dated.
**Next action**: the one thing to do next.
**Decisions**: dated list, newest first.
**Links**: repo, documents, people.
```
